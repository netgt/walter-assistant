# Walter — личный ассистент-оркестратор поверх Android

**Актуальная версия:** v1.48.0 (versionCode 265). Расширенный capability-роутер со статистикой запусков, Gmail OAuth и контур Gmail push через Pub/Sub bridge.

Walter — русскоязычный чат-ассистент, который не просто отвечает, а **выполняет действия на телефоне**: читает SMS и уведомления, работает с файлами и офисными документами, открывает приложения, следит за событиями по вашим правилам и исполняет многошаговые сценарии.

Языковая модель (DeepSeek или любой OpenAI-совместимый API) **анализирует и принимает решения**, а приложение **исполняет типизированные инструменты** и показывает результат в чате. Все данные и настройки хранятся **локально на устройстве**; своего сервера у Walter нет.

> Это исследовательский/личный проект. Он запрашивает широкие права (SMS, уведомления, все файлы) — ставьте и используйте осознанно.

## Возможности

- **Чат-первый интерфейс.** Один чат: запросы, ответы, карточки событий (пуши/SMS/почта/календарь), карточки файлов, баблы выполняющихся задач.
- **Инструменты чтения:** SMS, уведомления, установленные приложения, файлы и папки, поиск по файлам и по содержимому, системный промпт, история чата.
- **Файлы и документы:** чтение и полная перезапись `text/docx/xlsx/pptx/pdf`, создание файлов, поиск, просмотр офисных документов и PDF.
- **Веб и сервисы:** веб-поиск (Яндекс + DuckDuckGo), чтение страниц по URL, Telegram-каналы (`t.me/s`), почта по IMAP и Gmail OAuth, календари (системный + CalDAV), геокодинг/маршруты, Яндекс Диск (WebDAV + публичные ссылки).
- **Открытие приложений:** по точному имени (`open_app`) и **по функции** (`open_capability`: «галерея», «переводы», «навигация»…) через локальный capability-каталог с aliases и пользовательскими правилами. Статистика запусков помогает выбирать привычное приложение.
- **Оповещения (алерты):** правила на пуши / SMS / фоновые проверки; состояние порогов хранится в файле и переживает перезапуски.
- **Gmail push:** `users.watch` + Pub/Sub + Cloud Run bridge, отдельный каталог `gmail-push-bridge/` с инструкцией развёртывания.
- **Многошаговые планы** с разделителем `->` и словами-подтверждениями; вопросы пользователю ждут свободный ответ.
- **Режим лончера:** Walter можно сделать домашним приложением; тогда обычные системные уведомления скрываются, а события остаются в чате.
- **Память:** явные факты + журнал диалогов; поиск по всей истории (`search_history`).

Подробная логика и примеры — в [docs/USAGE.md](docs/USAGE.md).

## Как это работает

1. Вы пишете запрос в чат.
2. Приложение отправляет его модели вместе с системным промптом и памятью.
3. Модель возвращает **одно JSON-действие** (`read_sms`, `open_app`, `write_file`, `chat`, …).
4. Приложение исполняет действие локально и возвращает модели данные.
5. Модель либо запрашивает следующий инструмент, либо даёт финальный ответ (`chat`).

Для планов приложение само управляет границами шагов и подтверждениями (см. [USAGE](docs/USAGE.md)).

### Приватность

- Ключ API, память, история, настройки и файлы состояния алертов хранятся в `SharedPreferences`/файлах **на устройстве**.
- Внешние сервисы (поиск, почта, Диск, геокодер) вызываются только по вашим настройкам и ключам.
- В репозитории **нет** личных данных и ключей: подпись и секреты вынесены в gitignore-файлы.

## Сборка и установка

Требования: JDK 17, Android SDK (compileSdk 35), Gradle 8.13 (или wrapper).

```bash
./gradlew assembleDebug          # сборка debug-APK
./gradlew test                   # JVM-тесты
adb install app/build/outputs/apk/debug/app-debug.apk
```

Release-подпись берётся из локального `keystore.properties` (не публикуется). Без него сборка использует debug-подпись — этого достаточно, чтобы поставить приложение себе и друзьям.

После установки выдайте права в **Настройках Walter**: уведомления, SMS, доступ к уведомлениям (NLS), «Все файлы», календарь/геолокация по желанию. Добавьте ключ API в настройках модели.

## Структура проекта

```
app/src/main/java/com/example/dispatcher/
  MainActivity.kt      # UI, роутер, планы, реестр инструментов, действия
  RouterLogic.kt       # модели сообщений/событий, разбор JSON, PlanFlow (планы/подтверждения)
  AlertStore.kt        # оповещения и пресеты
  WatchEngine.kt       # оценка правил, файловое состояние, доставка алертов
  WatchService.kt      # NotificationListenerService (пуши, лончер-режим)
  SmsReceiver.kt       # приём SMS
  CapabilityRouter.kt  # открытие приложений по функции
  EventFilter.kt       # фильтры пушей/SMS
  HistorySearch.kt     # поиск по всей истории
  MemoryStore.kt       # память
  FileStore.kt / OfficeStore.kt / OfficeView.kt  # файлы и офисные форматы
  ...                  # почта, календарь, карты, поиск, Диск, Telegram
app/src/main/assets/capabilities.json  # capability-каталог
app/src/test/...       # JVM-тесты
```
